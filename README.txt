
BANK MANAGEMENT SYSTEM - CORE JAVA PROJECT

FEATURES:
- Create Bank Account
- Deposit Money
- Withdraw Money
- View Single Account
- View All Accounts

CONCEPTS USED:
- Core Java
- OOP Concepts
- Classes & Objects
- Encapsulation
- ArrayList
- Methods
- Exception Handling Basics

SOFTWARE REQUIRED:
- Java JDK
- VS Code / IntelliJ / Eclipse

HOW TO RUN:

1. Compile:
   javac *.java

2. Run:
   java BankManagementSystem
